### 🚀 What I'm Building

#### 🤖 [CreatorOS](https://github.com/AkhileshP19/creator-os/tree/dev)

**AI-Powered Content Management & Automation Platform**

CreatorOS is a full-stack platform I'm building for short-form content creators to manage content ideas and automate AI-assisted content generation, review, approval, and publishing workflows.

**Built so far:**
- Authenticated **Projects, Content Ideas, and Project Settings** workflows
- **Google Gemini** integration for structured AI script generation
- Persistent AI workflow orchestration for tracking provider, model, input, output, status, and errors
- **Google Flow** video-generation pipeline
- Generated asset storage using **Backblaze B2**
- Architecture for approval, review, asset management, and scheduled publishing workflows

**Stack:** Next.js • React.js • TypeScript • Tailwind CSS • shadcn/ui • Node.js • Express.js • PostgreSQL • Prisma • Neon • Clerk • Google Gemini • Google Flow • Backblaze B2

> 🚧 Currently under active development. The latest implementation is available on the `dev` branch.
